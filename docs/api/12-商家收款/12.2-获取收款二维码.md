# 12.2 获取收款二维码

> ← [文档索引](../../INDEX.md) · [API 总览](../README.md) · [12. 商家收款](./README.md) · [架构文档](../../ARCHITECTURE.md)

**封装状态**: ❌ 未封装

- **请求URL**: `/wxwork/GetUserMerchantQrCode`
- **请求方式**: POST
- **参数**:

| 参数名 | 必选 | 类型 | 说明 |
|--------|------|------|------|
| uuid | 是 | String | 实例唯一标识 |
| name | 是 | String | 商户名称 |
| amount | 是 | float | 金额 |
| mchid | 是 | String | 商户ID |

- **返回示例**:
```json
{
    "data": {
        "ret": 0,
        "qrcode_url": "http://127.0.0.1:8083/vdet6JKr2d00005c07ec97.png",
        "project_id": "vdet6JKr2d00005c07ec97"
    },
    "errcode": 0,
    "errmsg": "ok"
}
```
