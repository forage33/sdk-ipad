# 获取CDN初始化参数接口档

## 1. 简要描述
本接口用于获取CDN的初始化参数，基于企业微信的唯一标识（UUID）进行操作。
从账号服务进行获取，哪个账号需要操作cdn下载上传就要获取哪个账号的不要混用，不要获取一个账号的就全部都用这个。
此接口获取的信息可以缓存起来，1到2天更新一次就可以。
## 2. 请求信息

- **请求URL**: 
 - `http://47.94.7.218:8083/wxwork/GetCdnInfo`

- **请求方式**: 
  - `POST`
  
- **Content-Type**: 
  - `application/json`

## 3. 请求参数

| 参数名 | 必选 | 类型   | 说明                               |
|--------|------|--------|------------------------------------|
| uuid   | 是   | String | 每个实例的唯一标识，用于操作特定企业微信 |

### 3.1 请求示例

以下是请求的示例JSON格式：

```json
{
    "uuid": "f5a22e9b-9664-4250-b40a-08741dba549c"
}
```

## 4. 返回结果

### 4.1 响应参数说明

| 参数名   | 类型   | 说明                         |
|----------|--------|------------------------------|
| data     | Object | 返回的CDN信息对象           |
| errcode  | Int    | 错误代码，0表示成功         |
| errmsg   | String | 错误信息描述                |
