# 6.5 cdn上传网络图片

> ← [文档索引](../../INDEX.md) · [API 总览](../README.md) · [06. CDN 上传与下载](./README.md) · [架构文档](../../../ARCHITECTURE.md)

**分组**: 图片 · **SDK 方法**: `CdnUploadImgLinkIntegration` · **封装状态**: ✅ 已封装

## 简要描述

- CDN上传网络图片重置版

## 请求URL
- ` http://47.94.7.218:8083/wxwork/CdnUploadImgLink
  
## 请求方式
- POST 

- ContentType:"application/json"

## 参数

|参数名|必选|类型|说明|
|:----    |:---|:----- |-----   |
|url |是  |String |网络图片地址|

## 请求示例 

``` 
{
    "uuid":"094d0f95d60e8f1404c83114608be5f3",
    "url":"http://xxxx:8060/download/Img/20250331/66666.png"
}
```
