# 8.5 发送朋友圈评论

> ← [文档索引](../../INDEX.md) · [API 总览](../README.md) · [08. 朋友圈操作](./README.md) · [架构文档](../../../ARCHITECTURE.md)

**SDK 方法**: `CommentSns` · **封装状态**: ✅ 已封装

## 简要描述

- 发送朋友圈评论

## 请求URL
- ` http://47.94.7.218:8083/wxwork/CommentSnsReq
  
## 请求方式
- POST 

- ContentType:"application/json"

## 参数

| 参数名 | 必选 | 类型   | 说明                                         |
| :----- | :--- | :----- | -------------------------------------------- |
| uuid   | 是   | String | 每个实例的唯一标识，根据uuid操作具体企业微信 |
## 请求示例 

``` 
{
    "uuid":"1688857826547606",
    "ref_commentid":0, //评论id 默认传0  如果需要回复别人的评论则传别人评论的id 从获取朋友圈列表中获取
    "sid":7297137800987783140, //朋友圈消息对应的id
    "comment":"哈个头" //评论内容
}
```

## 返回示例 

``` 
{
    "data": {
        "commentid": 0
    },
    "errcode": 0,
    "errmsg": "ok"
}
```
