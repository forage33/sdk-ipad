    
##### 简要描述

- 企业用户id转开放平台代开发应用版本id

##### 请求URL
- ` http://47.94.7.218:8083/wxwork/vid2OpenUserTripartiteId
  
##### 请求方式
- POST 

- ContentType:"application/json"

##### 参数

|参数名|必选|类型|说明|
|:----    |:---|:----- |-----   |
|uuid |是  |String |每个实例的唯一标识，根据uuid操作具体企业微信|

##### 请求示例 

``` 
{
    "uuid": "fd382199fb886386a79a2d51fab90783",
    "scorpid": "wwa7a371f1026575c9",  //企业idscorpid
    "corpid": 1970325291998726, //企业id长整型版本
    "appId":5629499811733038, //应用id
    "user_id":[
        7881302555913738
    ]
}
```

##### 返回示例 

``` 
{
    "data": [
        {
            "user_id": 7881300143960291,
            "openid": "wmgizUDQAAwEpDeJjPdOnjKTzc3GsCAA"//对应开放平台 external_userid
        }
    ],
    "errcode": 0,
    "errmsg": "ok"
}
```
