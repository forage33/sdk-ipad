### 接口名称
获取大文件上传的参数走账号服务这个接口转换一下就可以去发送了。

### 接口概述
- `http://127.0.0.1:8084/wxwork/c2c_to_wwfile_id`

### 请求头
- `Content-Type`: `application/json`

### 请求参数

| 字段名       | 类型               | 描述                      |
|--------------|--------------------|---------------------------|
| uuid         | String             | 唯标识符               |
| file_id      | String             | 文件 ID                  |
| file_size    | long               | 文件大小（字节）         |
 |file_key     | String             | 文件密钥                 |

| file_md5     | String             | 文件的 MD5 哈希值        |
| file_name    | String             | 文件名称                 |

```json
    "file_name":"666.mp4"
}
```

### 返回值


| 参数名       | 类型        | 描述                                       |
|--------------|-------------|--------------------------------------------|
| md5          | 字符串     | 文件的MD5哈希值                           |
| filename     | 字符串     | 文件名                                    |
| file_id      | 字符串     | 文件唯一标识符                            |
| file_size    | 整数       | 文件大小，以字节为单位                    |
|_key     | 字符串     | 文件的唯一密钥                            |
| errcode      | 整数       | 错误代码，0表示成功                       |
| errmsg       | 字符串     | 错误信息，"ok"表示没有错误                 |

### 注意事项
- 请确保`auth_key`的有效性以避免认证失败。
- 上传的文件URL应指向有效且可访问的文件。
- 返回的`file_id`和`file_md5`可用于后续操作，例如验证和下载。
