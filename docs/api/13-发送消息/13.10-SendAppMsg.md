# 13.10 发送小程序

> ← [文档索引](../../INDEX.md) · [API 总览](../README.md) · [13. 发送消息](./README.md) · [架构文档](../../ARCHITECTURE.md)

**SDK 方法**: `SendAppMsg` · **封装状态**: ✅ 已封装

## 简要描述

- 发送小程序

## 请求URL
- ` http://47.94.7.218:8083/wxwork/SendAppMsg
  
## 请求方式
- POST 

- ContentType:"application/json"

## 参数

|参数名|必选|类型|说明|
|:----    |:---|:----- |-----   |
|uuid |是  |String |每个实例的唯一标识，根据uuid操作具体企业微信|
|send_userid |是  |long |要发送的人或群id|
|isRoom |是  |bool |是否是群消息|
