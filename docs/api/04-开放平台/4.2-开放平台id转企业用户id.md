    
##### 简要描述

- 开放平台id转企业用户id

##### 请求URL
- ` http://47.94.7.218:8083/wxwork/UserId2Vid
  
##### 请求方式
- POST 

- ContentType:"application/json"

##### 参数

|参数名|必选|类型|说明|
|:----    |:---|:----- |-----   |
|uuid |是  |String |每个实例的唯一标识，根据uuid操作具体企业微信|

##### 请求示例 

``` 
{
    "uuid": "fd382199fb886386a79a2d51fab90783",
    "scorpid": "wwa7a371f1026575c9", //企业id scorpId
    "corpid": 1970325291998726,// 企业id长整型
    "appId":5629499811733038, //应用id 控制台应用 从控制台分组下的应用列表获取
    "openid":[
        "wmotXidAAAV0GK9hgqmkTJs3jM4G6fQA" //要转换的开放平台id
    ]
}
```

##### 返回示例 

``` 
{
    "data": [
        {
            "user_id": 7881300143960291,
            "openid": "wmgizUDQAAwEpDeJjPdOnjKTzc3GsCAA"
        }
    ],
    "errcode": 0,
    "errmsg": "ok"
}
```
