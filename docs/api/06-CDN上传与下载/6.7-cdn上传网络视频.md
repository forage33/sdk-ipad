## 简要描述

- CDN上传网络视频

## 请求URL
- ` http://47.94.7.218:8083/wxwork/UploadCdnVideoLink
  
## 请求方式
- POST 

- ContentType:"application/json"

## 参数

|参数名|必选|类型|说明|
|:----    |:---|:----- |-----   |
|url |是  |String |网络图片地址|
