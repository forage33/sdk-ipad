**SDK 方法**: `GetColleaRemarkList` · **封装状态**: ✅ 已封装

## 简要描述

- 获取内部联系人备注列表

## 请求URL
- ` http://47.94.7.218:8083/wxwork/GetColleaRemarkList
  
## 请求方式
- POST 

- ContentType:"application/json"

## 参数

| 参数名 | 必选 | 类型   | 说明                                         |
| :----- | :--- | :----- | -------------------------------------------- |
| uuid   | 是   | String | 每个实例的唯一标识，根据uuid操作具体企业微信 |
## 请求示例 

``` 

{
    "uuid": "1688855749266556", 
    "limit": 100, 
    "seq": 0
}
```
