# 8.1 获取朋友圈列表

> ← [文档索引](../../INDEX.md) · [API 总览](../README.md) · [08. 朋友圈操作](./README.md) · [架构文档](../../../ARCHITECTURE.md)

**SDK 方法**: `GetSnsList` · **封装状态**: ✅ 已封装

## 简要描述

- 获取朋友圈列表

## 请求URL
- ` http://47.94.7.218:8083/wxwork/GetSnsList
  
## 请求方式
- POST 

- ContentType:"application/json"

## 参数

|参数名|必选|类型|说明|
|:----    |:---|:----- |-----   |
|uuid |是  |String |每个实例的唯一标识，根据uuid操作具体企业微信|
## 请求示例 

``` 
{
    "uuid":"168885379xxxx",
    "seq":-1,
    "limit":10
}
```
